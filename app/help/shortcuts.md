Shortcuts follow the menus; ⌘ stands for Ctrl on Linux and Windows. Single-letter keys act while the viewer has focus.

$$
\text{⌘} = \text{Ctrl},\qquad \text{⌥} = \text{Alt},\qquad \text{⇧} = \text{Shift}
$$

## File and edit

| Shortcut | Action |
|---|---|
| ⌘O · ⌘W | Open dataset · Close dataset |
| ⌘S · ⇧⌘S | Save pipeline · Save pipeline as |
| ⇧⌘E · ⌥⌘E | Export result · Export figure (current view) |
| ⌘Z · ⇧⌘Z | Undo · Redo |
| ⌘D · ⌫ · Space | Duplicate step · Remove step · Enable / skip step |
| ⌥↑ · ⌥↓ | Move step up · down |
| ⌘C · ⌘V | Copy parameters · Paste parameters |

## View

| Shortcut | Action |
|---|---|
| 1 · 2 · 3 | Ortho views · 3D volume · Compare raw vs. step |
| H · L | Crosshair · Labels overlay |
| O | Solo: only the selected label, in the slices and in 3D |
| + · − · 0 | Zoom in · Zoom out · Fit to window |
| ⇧A | Auto contrast (display) |
| V · P · M · R · B · E | Navigate · Probe · Measure · ROI · Paint · Erase |
| [ · ] | Smaller · larger brush |

## Process and segment

| Shortcut | Action |
|---|---|
| ⇧⌘A | Add operation |
| ⌘R · ⇧⌘R · Esc | Run all enabled · Run selected step · Cancel |
| ⌘M | Load Torch model |
| ⌘G · ⇧⌘G | Merge selected labels · Split label |
| → · ← | Next · previous flagged label |

## Window and help

| Shortcut | Action |
|---|---|
| ⌥1 … ⌥5 | Operations · Parameters · Diagnostics · Help page · Assistant |
| F1 · ⌘/ | Help for this step · Keyboard shortcuts |
| ⌘, · ⌘Q | Preferences · Quit |

## Parameters

| Parameter | Explanation |
|---|---|
| **Viewer focus** <br> click a pane | Single-key shortcuts (1, 2, 3, H, L, V, P, M, R, B, E, +, −, 0) act on the viewer only while one of its panes has keyboard focus. |

## Note

Shortcuts can be rebound in *Preferences ▸ Keys*.
